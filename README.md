## 📖 项目简介 (Overview)

**启灵商城（`qilingshop`）** 是一套面向 WordPress 及启灵生态深度定制的综合商业变现与多功能商城插件。

它不仅是一套简单的积分系统或单一商城插件，而是将 **积分体系、VIP 会员权益、付费资源下载、卡密自动发货、实物电商、拼团/助力/分销营销、全渠道支付、售后工单、多端小程序对接** 融为一体的数字化交易底座。

无论您是构建**数字资源站、知识付费平台、软件卡密发卡站、会员制社群，还是实物品牌电商与微信小程序私域商城**，启灵商城都能提供稳定、安全、可运营的完整交易闭环。

## ⚡ 核心功能特性 (Key Features)

### 1. 📁 付费资源与数字内容变现
* **多网盘深度支持**：原生支持百度网盘、阿里云盘、夸克网盘、123云盘、迅雷等主流网盘链接加密下载与跳转。
* **网盘有效性智能检测**：内置网盘链接失效检测，有效保障用户购买与下载体验。
* **付费阅读与隐藏内容**：支持文章局部内容购买后解锁，支持纯文本/代码隐藏、下载资源购买及组合形式。
* **灵活购买策略**：支持按积分购买、现金直购、VIP 免费特权、VIP 专属折扣、每日免费下载限额、免登录游客购买等。
* **批量管理与独立下载页**：支持资源批量编辑与配置，提供美观大气的独立资源下载与展示页。

### 2. 🛍️ 完整实物电商与虚拟商品系统
* **商品与规格管理**：支持实物商品与多规格 SKU、参数属性、分类层级与库存精细化管理。
* **自动化卡密系统**：虚拟卡密批量导入、下单即时自动发卡，支持订单退款/取消时自动回收卡密库存。
* **购物与结算链路**：完整的购物车、多收货地址管理、运费模板计算、快捷结算与实时支付拉起。
* **履约与物流追踪**：支持主流快递物流公司配置、发货面单管理与物流轨迹实时追踪。
* **售后与合规保障**：内置售后退款处理流程、工单售后支持系统、电子发票管理及商品真实评价互动。

### 3. 👑 VIP 会员与用户成长体系
* **多等级 VIP 运营**：支持月卡、季卡、年卡、终身会员等多种层级与定价配置。
* **差价升级机制**：老会员升级更高等级时自动计算差价补款，无缝升级权益。
* **积分与任务中心**：支持签到奖励、消费返积分、充值赠送、每日任务，积分流水透明可查。
* **卡密兑换码**：支持批量生成与管理 VIP 会员兑换码、注册邀请码及积分充值卡。

### 4. 🚀 社交电商与营销增长工具
* **优惠券系统**：支持全站通用券、品类券、商品专属券、新人首单券、生日关怀券，支持满减/折扣/门槛限制。
* **裂变拼团与好友助力**：支持限时拼团活动、好友助力砍价/裂变拉新，提升私域社群传播与转化。
* **分销推广联盟 (Affiliate)**：支持多级推广返佣、邀请奖励、阶梯返利及提现审核管理。
* **创作者分成 (Author Commission)**：支持文章作者/入驻创作者交易分润，打造多用户投稿共赢生态。
* **氛围营销**：支持实时成交弹幕广播（Trade Feed），增强购买信任感与转化率。

### 5. 💳 全渠道聚合支付网关
* **国内官方渠道**：支付宝（当面付 / 手机网站 / 电脑网站支付）、微信支付（Native / JSAPI / H5 / 微信小程序支付）。
* **免签/聚合支付**：支持彩虹易支付（EPay）、虎皮椒/讯虎支付（XhPay）等聚合接口。
* **国际跨境支付**：支持 PayPal、Stripe 跨境信用卡与海外结算。
* **站内钱包**：支持账户余额充值、余额直购及积分抵扣结算。

### 6. 📱 小程序与移动端无缝互通
* 提供标准化 REST API 接口，与 **Uni-app** 及 **微信小程序** 深度互通。
* 小程序端完整承接：商品展示、购物车、微信支付、订单履约、积分签到、拼团助力、售后退款与物流查询。

### 7. 🎨 可视化店铺装修与运营看板
* **模块化装修**：支持轮播图、分类金刚区、拼团/秒杀专区、优惠券浮窗、瀑布流商品列表等组件自由拖拽组合。
* **多维度数据看板**：全景掌握销售额、订单量、客单价、用户留存、畅销排行及财务流水。

## 📦 安装与快速上手 (Installation & Setup)

1. **获取源码与插件包**：
   将 `qilingshop` 目录上传至 WordPress 网站的 `/wp-content/plugins/` 目录中。
2. **激活插件**：
   登录 WordPress 管理后台，进入 `插件` -> `已安装插件`，找到 **启灵商城** 并点击 **启用**。
3. **完成授权与激活**：
   在后台根据指引绑定商业授权以激活全部核心高级功能与生态服务。
4. **基础配置**：
   * 进入后台 `启灵商城` -> `基础设置`，设置货币符号、积分兑换比例与充值选项。
   * 进入 `支付配置`，填入商户参数并开启支付宝、微信支付等支付通道。
   * 进入 `商品管理` / `资源管理`，开始上架您的第一批数字资源或实物商品。
